A README file is a document that explains your project to other people.

For example, a GitHub project's README can contain:

📌 Project name
📝 Project description
✨ Features
🛠️ Technologies used
⚙️ Installation steps
▶️ How to run the project
📸 Screenshots
📂 Project structure
🤝 Contributing
📄 License
👨‍💻 Author information

Usually the file is named README.md, where .md means Markdown.
